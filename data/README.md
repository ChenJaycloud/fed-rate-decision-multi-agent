# 本地输入数据

仓库不发布原始输入工作簿。三份 Notebook 使用同一套数据输入；运行前请在此目录准备有权使用的数据：

```text
data/
├── 美国数据.xlsx
└── 各国利率决议时间数据/
    └── 美联储利率决议.xlsx
```

`美国数据.xlsx` 的首行须包含样本构造器要求的中文字段名；字段定义、频率和序列线索见 [`../docs/data_sources.md`](../docs/data_sources.md) 与 Notebook 中的 `US_HEADER_MAP`。数据行需具有可解析的日期列和相应月度/季度值。请保持频率、单位和计算定义一致，不要只改列名来掩盖口径差异。

决议工作簿用于读取会议月份和目标利率水平，再按相邻决议间的利率变动映射到七档标签。请检查工作表结构与日期格式是否符合样本构造器。

项目原始文件夹中还包括人工整理表、不同来源的原始序列、研究中间表及多个版本的模型日志；它们没有整体打包公开。FRED 是数据平台，不代表所有序列均由美联储编制；公开或重新分发数据前，须分别核对原始机构的许可与数据条款。
