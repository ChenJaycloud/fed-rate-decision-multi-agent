# 美联储利率决议预测：多智能体协同框架

这是一个面向研究与求职展示的实验代码整理版。项目使用多种货币政策规则视角对同一决议样本分别形成判断，再由分析层整理分歧并交由决策层输出离散利率变动标签。当前公开包选取 System C（训练集文字记忆）笔记本作为代表实现。

> 这是历史样本上的研究原型，不构成投资建议，也不保证对未来决议有效。仓库没有附带原始数据、运行记录或实证结果；请勿把未复核的实验输出写成性能结论。

## 方法概览

- **预测对象：** 美联储目标利率变动，按代码中的七档标签进行分类（从低于 `-50bp` 到高于 `50bp`，含零变动档）。
- **理论判断：** 七类规则智能体，包括标准 Taylor 规则、前瞻型 Taylor 规则、利率平滑、开放经济规则、金融稳定规则、新凯恩斯最优规则和平衡方法。
- **协同流程：** 样本构造 → 理论智能体 → 分歧分析与决策交接 → 决策层。System C 会基于训练样本生成文字反思记录和汇总记忆，再用于测试阶段；代码没有实现自动提示词优化。
- **时间划分：** 当前实现以 2015-01-01 为训练/测试分界，训练样本早于该日期，测试样本不早于该日期。该划分不等同于完整的实时回测设计。

## 环境与运行

需要 Python 3.10 或更高版本。先按 `data/README.md` 准备数据；仓库不提供数据文件，原始数据格式和表头必须符合笔记本内的样本构造器。Windows PowerShell 示例：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
jupyter notebook
```

编辑本地 `.env`，填入你自己的 `DEEPSEEK_API_KEY`。`.env` 已被 Git 忽略。也可以在启动 Jupyter 前设置同名环境变量。打开 `rate_decision_system_c.ipynb` 后按顺序运行代码单元。笔记本会先构建运行配置；完整训练和预测调用已设为显式选择，需在确认数据、模型服务和费用后，取消最后单元中的调用注释并执行。运行产物会写入 `artifacts/`，不会作为本仓库内容提交。

训练反思与推理会把样本内容发送给配置的模型服务。请先确认数据的使用和传输权限，并评估调用成本。不要把 API 密钥写进代码、笔记本单元或提交记录。

## 可复现性与边界

原始项目没有提供锁定的依赖版本，也没有随本公开版附上数据和已验证的模型结果；因此不同环境下的运行时间、API 响应及预测结果可能不同。数据版本、指标发布日期、修订数据、信息集的实际可得性和历史测试策略均会影响结果。公开仓库不宣称模型优于基准，也不报告未经本次清理验证的准确率。
