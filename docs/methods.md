# 三种训练方式与共同预测流程

## 共同框架

每个决议月份先构造统一的宏观与政策路径信息集，并供七个货币政策理论智能体分别判断。理论层覆盖标准与前瞻性 Taylor 规则、利率平滑、平衡方法、开放经济、金融稳定和新凯恩斯最优规则。分析交接层把各智能体的标签分布、理由、关键变量、共识、分歧与风险压缩成结构化证据包；决策层根据所在 Notebook 的方法设定输出七档利率变动标签。

三种实现共用样本构造、理论输入和分析交接的主干，核心差异是训练期经验如何进入决策层。

## 方法对照

| 方法 | 是否使用训练集 | 训练阶段产生什么 | 测试阶段如何决策 |
|---|---:|---|---|
| 无训练的理论判断直接汇总 | 否 | 不生成训练权重或反思记忆 | 按预设聚合逻辑整合理论判断 |
| 训练集数值权重 | 是 | 根据各理论输出对训练期真实标签的支持情况形成数值权重，并冻结权重 | 当前样本的理论输出按冻结权重汇总 |
| 训练集文字反思记忆 | 是 | 将训练期预测、真实标签及错判情形整理为适用条件、反例和边界说明 | 当前样本先形成理论证据，再由决策层参照冻结的经验记忆判断 |

### 无训练的理论判断直接汇总

该方法提供不依赖训练经验的参照。它保留理论层与分析层，但不更新数值权重、不形成训练集反思记忆，也不读取训练期冻结快照。它用于比较：只靠共享理论判断与预设聚合逻辑能达到什么结果。

Notebook：[`01_direct_aggregation_no_training.ipynb`](../notebooks/01_direct_aggregation_no_training.ipynb)。

### 训练集数值权重

训练期按历史样本累积理论输出对真实标签的支持信息，据此形成决策层使用的数值权重。进入测试期后，权重作为冻结配置读取；测试样本标签不参与更新。该方案把“哪些理论在训练期更有支持”压缩成显式参数，便于检查权重变化。

Notebook：[`02_training_set_numeric_weights.ipynb`](../notebooks/02_training_set_numeric_weights.ipynb)。

### 训练集文字反思记忆

训练期先生成理论与决策判断，再用真实标签回看预测案例，记录理论信号的帮助、误导、适用条件和特殊情形，汇总为文字记忆。测试期只检索冻结记忆，不用测试期真实标签继续反思或改写规则。

Notebook：[`03_training_set_reflection_memory.ipynb`](../notebooks/03_training_set_reflection_memory.ipynb)。

## 信息边界与解释限制

三个方法的相同测试月份和标签口径提供了并列比较基础，但历史运行仍受数据版本、提示词、模型服务版本与运行参数影响。当前项目使用历史修订宏观序列，不能据此断言当时决策者实际可见这些数值。各方法结果适合作为一个固定实验设置下的探索性对照，不等同于严格实时回测或样本外稳健性结论。
