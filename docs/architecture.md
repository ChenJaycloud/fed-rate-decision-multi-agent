# 系统架构

![三种训练方式共用的多智能体架构](assets/three_methods_architecture.svg)

## 共享预测主干

1. **会议月信息集**：宏观变量、此前政策路径和预期指标进入统一样本结构。
2. **理论判断层**：七个货币政策规则智能体分别给出标签分布、依据和关键变量。
3. **分析交接层**：将个体判断整理为共识、分歧、冲突来源与不确定性，传递给决策层。
4. **方法化决策层**：通过无训练直接汇总、数值权重或文字反思记忆三种方式生成最终标签。
5. **结果评估层**：将预测与真实标签对照，汇总准确率、分类误差与逐期记录。

## 三种方法在哪一层分叉

共同理论判断层和分析交接层在三个 Notebook 中保持相同设计目标。差异集中在决策层前后的训练经验：第一种不训练；第二种从训练样本形成并冻结数值权重；第三种从训练样本形成并冻结文字反思记忆。测试阶段不使用测试标签更新训练产物。

项目流程和三种方法细节见[方法说明](methods.md)。图示只表达代码中的模块关系，不代表模型已经具备线上或实时交易能力。
