# System C 架构与预测流程

![System C 多智能体协同预测架构](assets/system_c_architecture.svg)

## 1. 输入与任务

样本以决议月份为索引，模型读取通胀、产出、就业、预期、外部条件、金融稳定和政策路径等结构化变量，并预测目标利率变动的七档区间。当前公开代码将会议日期映射到月份首日；样本日期用于连接宏观面板，不代表精确的 FOMC 公告日。

## 2. 七类理论判断

所有理论智能体读取同一会议样本，但受各自规则和变量范围约束，分别生成固定结构的判断：推荐标签、概率分布、置信度、理由、关键变量、适用性边界和风险说明。

1. 标准 Taylor 规则
2. 前瞻性 Taylor 规则
3. 利率平滑规则
4. 平衡方法规则
5. 开放经济规则
6. 金融稳定规则
7. 新凯恩斯最优规则

它们表示规则化的政策判断视角，不对应具体的 FOMC 委员或经济学家。

## 3. 分析交接与最终决策

分析交接层对七组输出进行校验和归纳，将共识方向、标签差异、理由、风险和不确定性整理为决策层可读的结构化证据。决策层综合当前证据及训练期记忆，输出最终七分类标签、概率分布、主要和辅助理论、解释与剩余不确定性。Notebook 通过 LangGraph 组织训练或预测流程，模型请求由 OpenAI 兼容接口后端发送。

## 4. 训练记忆与信息隔离

System C 的训练期流程在每个样本预测完成后，使用真实标签形成样本级反思；训练期结束后再将反思汇总成理论适用性记忆。预测期只读取这份已冻结记忆，不能利用预测期真实标签更新记忆。记忆用于提示适用条件、冲突处理和边界，不等同于对理论 Agent 参数或提示词的自动优化。

## 5. 公开实现范围

当前公开 Notebook 聚焦 System C。总体研究中的 System A（无训练直接聚合）和 System B（训练集数值权重）在论文草稿中作为对照设定报告，但没有随该公开包提供完整实现。因此，架构图只画出公开代码对应的 System C 流程；对照结果在结果说明中单独标注来源。

## 6. 当前复现边界

仓库没有附带输入数据、API 响应或运行轨迹。模型服务版本、历史数据修订、发布日期和预测调用随机性都会影响结果。代码按样本月份读取不晚于索引月份的观测值，但没有完整的历史数据版本和逐指标发布日期对齐；因此目前不应将结果称为严格的实时信息集回测。
